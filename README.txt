Upload ALL files in this folder to the web root of your site (or subdomain):
  index.html, sw.js, manifest.webmanifest, icon.svg, icon-192.png, icon-512.png

The site must be served over HTTPS for offline use and "Add to home screen" to work.
To update the app later, replace index.html with the new one. If you also change sw.js,
bump the version string V at the top of sw.js so phones pick up the new files.

Works here: all calculators, sheets, schematics, reports, PDF/Excel/CSV export, offline use.
Not available outside Claude: team sharing (each device keeps its own data).
